# Planeta Crăciun — Cluj-Napoca 2026

Site public: https://saliery95.github.io/planeta-craciun-cluj-2026/

Versiune statică pentru GitHub Pages, exportată din proiectul Planeta Crăciun (sursă `b9fb019b4033460b27e58186d76d508708bfbd51`). Include programul atelierelor, harta interactivă și materialele video pentru desktop și mobil.

GitHub Pages publică ramura `main`, directorul rădăcină `/`. Fișierul `.nojekyll` păstrează fișierele statice fără procesare Jekyll. Resursele sunt relative, astfel încât site-ul funcționează în subdirectorul repository-ului.

## Actualizare

Copiază conținutul final al directorului `dist` din proiectul principal în acest repository. Păstrează `.nojekyll` și README-ul, omite `_headers` (GitHub Pages nu îl aplică) și folosește adresa GitHub Pages pentru imaginea Open Graph. Publică modificările pe `main`; Pages actualizează site-ul automat.

Politica CSP și referrer sunt păstrate în metadatele HTML. Site-ul nu utilizează backend, autentificare sau chei API. Marcajul noindex este păstrat pentru această versiune de prezentare.

Ilustrațiile și materialele evenimentului sunt publicate pentru prezentarea site-ului; publicarea repository-ului nu acordă o licență de reutilizare a acestora.

## Regulamente de participare

Secțiunea [Regulamente](https://saliery95.github.io/planeta-craciun-cluj-2026/#regulamente) oferă documentele furnizate de organizator în română, engleză, franceză, germană și maghiară. Regulamentul integral apare automat la finalul paginii, în limba site-ului, cu un link de descărcare a originalului DOCX, păstrat nemodificat. Documentul francez furnizat de organizator este afișat integral pe pagina franceză.

Paginile de citire sunt în `regulamente/`, originalele în `assets/regulations/`. Aceste copii sunt actualizate din proiectul principal la publicare și nu se sincronizează automat cu Drive. Materialele de grafică din 2025 nu sunt folosite ca regulament pentru 2026.

Programul este împărțit în Muzică, Căsuța Moșului, Momente speciale, Campanii și Atracții. Calendarul atelierelor arată câte o zi, păstrând toate cele 34 de date. Orele și tarifele neanunțate sunt marcate explicit.
